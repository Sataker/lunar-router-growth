# Lunar Router: growth strategy

Organic growth plan for an open-source LLM router, from positioning to content for Reddit and X.

Live at https://sataker.github.io/lunar-router-growth/

- `index.html`: strategy overview
- `showcase.html`: content by platform
- `stories.html`: story posts
- `content-calendar-v2.md`, `reddit-posts-v3.md`, `tweets-v3.md`: source content, with PDF versions

Lunar Router was the project's earlier name. It is now [OpenTracy](https://github.com/OpenTracy/OpenTracy).

No build step: GitHub Pages serves these files directly from `main`. To preview locally, run `python3 -m http.server` and open http://localhost:8000.
